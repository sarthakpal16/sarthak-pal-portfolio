# Logo and icon sources

All assets are self-hosted under `dist/assets/`. Vector files were rebuilt from path data only, with no scripts, links or embedded images. Company and university marks are trademarks of their owners. They are used only to identify Sarthak's employers and schools next to their names, and are shown decoratively (`alt=""`, inside `aria-hidden` tiles) because each name is visible as text beside its mark.

| Asset | Source | Notes |
| --- | --- | --- |
| `logo-citi.svg` | Citi's own site header, citigroup.com/global (inline base64 SVG), fetched 2026-11-22 | Paths and colors (#255BE3, #FF3C28) unchanged; the variant without ® |
| `logo-beganto.png` | beganto.com header logo, wp-content/uploads/2024/01/beganto-logo.png | Square "b" mark cropped from the official wordmark. Company verified: CIN U72900DL2004PTC124803 (Beganto Software Systems Pvt Ltd) lists Sunil Grover as a director, and CB Insights names him CEO of beganto.com. The site calls itself "Beganto Software Solutions". Crop is 86x81 px, so it is slightly soft on 3x screens |
| `logo-paytm.svg` | paytm.com header, pwebassets.paytm.com/commonwebassets/paytmweb/header/images/logo.svg | Only the navy/cyan "Paytm" wordmark paths kept; the "loves UPI" lockup removed |
| `logo-asu.png` | asu.edu header, asu_brand/dist/assets/img/arizona-state-university-logo-vertical.png | The "ASU" sunburst mark cropped from the official vertical logo, without the university-name text below it |
| `logo-iiitd.png` | iiitd.ac.in/about/graphic-identity, sites/default/files/images/graphicidentity/logo.jpg | Official mark, trimmed to its edges, on a white tile |
| `tech-icons.svg` (python, apachespark, apachekafka, neo4j, langgraph, react, nodedotjs) | Simple Icons 16.38.1 (npm, CC0-1.0 icon data) | Single-color paths drawn in the text color. Brand guidelines apply: python.org/community/logos, apache.org/foundation/marks, neo4j.com/brand, nodejs.org/en/about/branding |
| `tech-icons.svg` (database, server, queue) | Original generic glyphs drawn for this site | Fallbacks: a database glyph for SQL; a server glyph for AWS EC2 and a queue glyph for SQS.
